# Community Stages

새 스테이지는 저장소 루트의 [CONTRIBUTING.md](../CONTRIBUTING.md)를 따릅니다.

- 게임: `community-stages/<stage-slug>/index.html`
- 메타: `community-stages/<stage-slug>/meta.json`
- 목록: `community-stages/registry.js` (`node relay-tools/scripts/sync_registry.js`로 생성)
- 갤러리: `gallery.html`
- 개별 플레이: `play.html`
- 검증용 런처: `index.html`

에셋과 썸네일(`thumbnail.png`)은 스테이지 폴더에 함께 둡니다.
